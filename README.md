# 极简待办清单 To-Do List

一个用 **纯原生 HTML + CSS + JavaScript** 写成的网页版待办清单，没有框架、没有依赖、没有构建步骤 —— 双击 `index.html` 就能用。

界面是一张居中的白色卡片，圆角 + 柔和阴影，手机上也能正常使用。

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 添加任务 | 在输入框输入内容，点击「添加」按钮，或直接按 <kbd>Enter</kbd> 键 |
| 标记完成 | 勾选任务左侧的复选框，任务文字会变灰并加上删除线，再次点击可取消 |
| 删除任务 | 点击任务右侧的「删除」按钮，该项立即从列表中移除 |
| 本地持久化 | 任务保存在浏览器 `localStorage` 中，刷新页面或关闭浏览器后重新打开都不会丢失 |
| 空状态提示 | 列表为空时显示「还没有任务，添加一个吧～」 |
| 响应式界面 | 卡片最大宽度 440px，自动居中，适配手机与电脑屏幕 |
| 轻量动画 | 新增任务时有渐入动画，按钮和输入框有悬停 / 聚焦反馈 |

### 交互细节

- 输入内容为空白（或只有空格）时，不会添加任务，输入框会自动重新聚焦。
- 单个任务最长 100 个字符。
- 任务较多、文字过长时会自动换行，不会撑破卡片布局。
- 任务顺序为添加顺序，最新的任务排在列表末尾。

## 快速开始

### 方式一：直接打开（推荐）

把项目下载到本地，双击 `index.html`，浏览器即可运行。

不需要安装 Node.js，不需要 `npm install`，也不需要启动本地服务器。

### 方式二：用本地静态服务器打开（可选）

如果你习惯通过 `http://` 访问，任选一种方式在项目目录下启动即可：

```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js（需先安装 http-server）
npx http-server -p 8000
```

然后浏览器访问 `http://localhost:8000`。

### 方式三：克隆仓库

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>
```

再双击 `index.html`。

## 使用说明

1. **新增任务**：在页面中间的输入框里输入待办事项，例如「写周报」，然后点击右侧「添加」按钮或按回车。
2. **标记完成**：做完一件事，勾选它左边的复选框，文字会变灰并划掉；点错了再点一次复选框即可取消。
3. **删除任务**：不需要的任务，点击右侧「删除」按钮移除。
4. **数据保留**：以上操作都会自动保存，刷新页面后任务原样还在。

---

## 数据存储说明

- 数据保存在浏览器的 `localStorage` 中，存储键名为 `todo-list.items`。
- 数据格式为 JSON 数组，每一项形如：

  ```json
  { "id": "m1b2c3d4e5", "text": "写周报", "completed": false }
  ```

- 数据只存在于**当前浏览器 + 当前设备**，换浏览器或换电脑看不到；不会上传到任何服务器。
- 清除浏览器缓存 / 站点数据，或在无痕窗口中关闭页面，都会导致任务列表被清空。

## 技术实现要点

- **零依赖**：不引入任何第三方库或框架，纯 HTML / CSS / 原生 JavaScript。
- **单一数据源**：所有任务存放在一个 `todos` 数组中，任何增删改后统一写入 `localStorage` 并重新渲染，避免 DOM 与数据不一致。
- **事件委托**：勾选与删除事件绑定在列表容器上，而不是每个按钮上，新增任务无需重新绑定。
- **XSS 防护**：任务文字通过 `textContent` 写入页面，而不是拼接 HTML 字符串，用户输入不会被当作代码执行。
- **读取容错**：解析 `localStorage` 数据时使用 `try/catch`，数据损坏或格式异常时自动回退成空列表，不会白屏。

## 浏览器兼容性

支持所有现代浏览器：Chrome、Edge、Firefox、Safari 及其移动端版本。

使用的 API 均为长期稳定特性（`localStorage`、`Array.prototype.find/filter`、`Element.closest`、`CSS 变量`、`Flexbox`），无需 polyfill。

> 注意：`localStorage` 在部分浏览器的 `file://` 协议下受限。若双击打开后任务无法保存，请改用上面的「方式二」通过本地服务器访问。

## 常见问题

**Q：刷新后任务不见了？**
A：先确认没有开启无痕 / 隐私模式，并检查浏览器是否允许本站点保存本地数据；若是通过 `file://` 直接打开，建议改用本地服务器访问。

**Q：可以多人共享同一个清单吗？**
A：不可以。本项目是纯前端本地应用，没有后端和账号体系，数据只保存在你自己的浏览器里。

**Q：想清空全部任务怎么办？**
A：逐个点击「删除」即可；或在浏览器开发者工具中执行 `localStorage.removeItem('todo-list.items')` 后刷新页面。

**Q：可以改成深色主题吗？**
A：可以。样式集中在 `style.css` 中，修改 `body` 的背景渐变、`.card` 的背景色与相关颜色变量即可。
